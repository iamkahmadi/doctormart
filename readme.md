# 🩺 DoctorMart - Pharmacy Management System

**DoctorMart** is a PHP & MySQL-based web application designed to simplify the management of a pharmacy’s operations. It includes features such as user authentication, product & category management, client orders, sales reporting, and more. This system is ideal for small to medium-sized pharmacies looking to digitize and streamline their business processes.

---

## 🛠 Features

- 🔐 User authentication (Login/Register)
- 📦 Product and category management
- 🧾 Client and admin order processing
- 📊 Dynamic sales and expiry reports
- 📈 Google Charts integration for analytics
- 🧑 User management
- 🧮 Stock and expiry monitoring
- 🖨️ Invoice generation & printing

---

## 🚀 Getting Started

### 📌 Prerequisites

- PHP 7.x or higher
- MySQL/MariaDB
- Apache/Nginx
- Composer (optional)

### 🔧 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/iamkahmadi/doctormart.git
   cd doctormart
   ```

2. Set up the database:
   - Import one of the `.sql` files in the `database/` folder (recommended: `nowdemy_pharmacy_v4.sql`) into your MySQL server.

3. Configure the database connection:
   - Edit the `connect.php` and `php_action/db_connect.php` files with your DB credentials.

4. Launch the app:
   - Serve with a local PHP server or place the files inside your web server's root directory.
